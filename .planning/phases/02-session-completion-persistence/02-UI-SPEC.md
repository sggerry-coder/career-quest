- **Button labels:** Body size (14px), semibold 600 -- matches existing `.cq-button` pattern with `font-weight: 600`
- **Toast/banner text:** Body size (14px), regular 400, `text-white/80`

Source: Detected from existing components -- `text-xl font-semibold` in headings, `text-sm` for body, `text-xs` for labels throughout `components/quest/` and `components/badges/`.

## Interaction Contracts

### 1. Completion Screen Entry (after badge_unlock + comparison_hint)

- **Trigger:** `onSessionComplete` callback fires from reveal-sequence
- **Confetti:** Canvas-confetti burst, 1-2 second duration, particles in `--cq-primary` and `--cq-accent` colors. Fire from center-bottom, spread 60 degrees.
- **Checkmark animation:** SVG circle + checkmark stroke-dashoffset animation, 0.8s duration, `--cq-accent` stroke color, easing `ease-out`
- **Heading:** Fade-in after checkmark completes (0.8s delay), `motion.h1` with `initial={{ opacity: 0, y: 20 }}` `animate={{ opacity: 1, y: 0 }}`
- **Summary cards:** Stagger-in 0.15s apart after heading (1.2s total delay), static score summaries
- **CTA buttons:** Fade-in last (1.8s delay). Two buttons: "View Dashboard" (primary) and "Save & Exit" (ghost)
- **Reduced motion:** Skip confetti and stroke animation. Show static checkmark and immediate content.

### 2. Persistence Flow

- **Trigger:** Completion screen renders, final checkpoint fires automatically
- **Happy path:** No UI change. Data saves silently in background.
- **Auto-retry:** 3 attempts with exponential backoff (1s, 2s, 4s). No UI during retries.
- **Failure (network/timeout):** After 3 failed retries, slide-up `PersistenceBanner` from bottom. Height 56px, `--cq-error-bg` background, `--cq-error` left border (3px). Contains failure message + "Retry" button (primary style, compact).
- **Failure (auth/permission):** Same banner but with "Your session expired. Please sign in again." + "Sign In" button that redirects to auth flow.
- **Retry success:** Banner slides down with "Saved!" flash in `--cq-success` color, then dismisses after 1.5s.
- **Non-blocking:** Banner does not cover or obscure the completion screen content. Positioned fixed at viewport bottom with 16px padding.

### 3. Save & Exit Flow

- **Trigger:** User taps "Save & Exit" on completion screen
- **If persistence already succeeded:** Show `ConfirmationToast` "Your progress is saved!" with checkmark icon, auto-dismiss after 2s, then redirect to landing page (`/`)
- **If persistence still pending/failed:** Trigger one final save attempt. On success, show toast + redirect. On failure, show `PersistenceBanner` (do not redirect).

### 4. Return User Redirect

- **Trigger:** User with `has_completed_session1 = true` visits `/` or `/quest/session/1`
- **Behavior:** Server-side or early client-side redirect to `/quest/dashboard`
- **Dashboard awareness:** Dashboard checks `has_completed_session1`. If true, renders saved scores. If false, renders empty state with CTA to start quest.

## Animation Specifications

All animations use Framer Motion (existing dependency) except confetti.

| Animation | Library | Duration | Easing |
|-----------|---------|----------|--------|
| Confetti burst | canvas-confetti (new dep) | 1.5s | gravity-based (library default) |
| Checkmark stroke | CSS `stroke-dashoffset` or Framer Motion `pathLength` | 0.8s | ease-out |
| Heading fade-in | Framer Motion | 0.4s, 0.8s delay | ease-out |
| Summary cards stagger | Framer Motion | 0.3s each, 0.15s stagger, 1.2s initial delay | ease-out |
| CTA buttons fade-in | Framer Motion | 0.3s, 1.8s delay | ease-out |
| Banner slide-up | Framer Motion | 0.3s | ease-out |
| Banner dismiss | Framer Motion | 0.2s | ease-in |
| Toast appear | Framer Motion | 0.2s | ease-out |
| Toast dismiss | Framer Motion | 0.2s, 2s auto-dismiss delay | ease-in |

Reduced motion: All durations collapse to 0.01ms per existing `@media (prefers-reduced-motion)` rule in globals.css.
