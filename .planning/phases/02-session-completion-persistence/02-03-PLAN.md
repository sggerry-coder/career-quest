    4. **Create retry handler:**
       ```typescript
       const handleRetryPersist = useCallback(async () => {
         setPersistResult(null); // Clear error state
         const result = await actions.persistCheckpoint("final");
         setPersistResult(result);
       }, [actions]);
       ```

    5. **Create sign-in handler:**
       ```typescript
       const handleSignIn = useCallback(() => {
         router.push("/");
       }, [router]);
       ```

    6. **Create save-and-exit handler:**
       ```typescript
       const handleSaveExit = useCallback(async () => {
         if (persistResult?.success) {
           // Already saved successfully
           setShowSaveToast(true);
           setTimeout(() => router.push("/"), 2200);
         } else {
           // Try one more time
           const result = await actions.persistCheckpoint("final");
           setPersistResult(result);
           if (result.success) {
             setShowSaveToast(true);
             setTimeout(() => router.push("/"), 2200);
           }
           // If failed, PersistenceBanner will show in CompletionScreen
         }
       }, [persistResult, actions, router]);
       ```

    7. **Trigger persist on session_complete** -- Add useEffect that fires when `questState.flowPhase === "complete"`:
       ```typescript
       useEffect(() => {
         if (questState.flowPhase === "complete" && persistResult === null) {
           handleFinalPersist();
         }
       }, [questState.flowPhase, persistResult, handleFinalPersist]);
       ```
       Note: The quest reducer sets flowPhase to "complete" via COMPLETE_SESSION action. The reveal sequence's onSessionComplete callback dispatches this. The persist fires after the UI has transitioned to the session_complete reveal phase.
