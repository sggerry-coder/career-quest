**INITIAL_STATE** -- all fields with sensible defaults: `flowPhase: "questions"`, `currentIndex: 0`, `direction: "right"`, `engagementShown: false`, `avatarClass: "wanderer"`, `current_block: "warmup"`, etc.

**questReducer(state, action) implementation:**

`ANSWER_QUESTION` case (the critical FLOW-01 fix):
1. Compute `nextIndex = state.currentIndex + 1`
2. Build `newResponses = [...state.responses, action.response]`
3. Compute `questionsAnswered = state.questions_answered + 1`
4. Check discovery mode: if `!state.discovery_mode_active && action.question.block === "riasec" && action.question.question_type === "likert"`, count consecutive neutrals (response_value === 3). If 3+, set `discovery_mode_active: true`.
5. Check engagement: find riasec block start index from `action.sessionQuestions` (`sessionQuestions.findIndex(q => q.block === "riasec")`). If `nextIndex === riasecStartIndex + 7 && !state.engagementShown && action.question.block === "riasec"`, return state with `flowPhase: "engagement"`, `engagementShown: true`, `currentIndex: nextIndex` (ATOMIC).
6. Check block transition: if `action.sessionQuestions[nextIndex]?.block !== action.question.block && nextIndex < action.sessionQuestions.length`, return state with `flowPhase: "block_transition"`, compute narration key from block pair.
7. Check end of questions: if `nextIndex >= action.sessionQuestions.length`, return state with `flowPhase: "selfmap"`.
8. Default: return state with `currentIndex: nextIndex`, `flowPhase: "questions"`.

`ANSWER_IPSATIVE` case: same flow logic as ANSWER_QUESTION (engagement check, block transition, end-of-questions) but response is pre-built by caller.

`DISMISS_ENGAGEMENT`: return `{ ...state, flowPhase: "questions" }`.

`DISMISS_BLOCK_TRANSITION`: return `{ ...state, flowPhase: "questions", current_block: state.responses.length > 0 ? deriveCurrentBlock(state) : state.current_block }`. Actually simpler -- derive current_block from `sessionQuestions[state.currentIndex].block` but we don't have sessionQuestions here. Just set `flowPhase: "questions"`.

`UNDO`: if `!state.last_response_undoable || state.responses.length === 0`, return state unchanged. Otherwise: `responses: state.responses.slice(0, -1)`, `questions_answered - 1`, `currentIndex: Math.max(0, state.currentIndex - 1)`, `last_response_undoable: false`, `direction: "left"`.

`SHOW_DISCOVERY`: `flowPhase: "discovery_prompt"`.
`DISMISS_DISCOVERY`: `flowPhase: "questions"`, `discovery_mode_active: true`.
`ENTER_SELFMAP`: `flowPhase: "selfmap"`.
`ENTER_REVEAL`: `flowPhase: "reveal"`.
`ENTER_CONFIRMATORY`: `flowPhase: "confirmatory"`, `adaptiveQuestions: action.adaptiveQuestions`, `confirmIndex: 0`.
`ANSWER_CONFIRMATORY`: increment `confirmIndex`, add response. If `confirmIndex + 1 >= state.adaptiveQuestions.length`, set `flowPhase: "complete"`.
`COMPLETE_SESSION`: `flowPhase: "complete"`.
`SKIP`: advance `currentIndex + 1`, check block transition and end-of-questions (same logic as ANSWER_QUESTION but no response added).
`SET_AVATAR_CLASS`: `avatarClass: action.avatarClass`.
